# Frontend — Processamento de Pedidos

React + TypeScript (Vite). Ver o README na raiz do repositório para visão geral da arquitetura e instruções de execução via Docker Compose.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Variáveis de ambiente (arquivo `.env`, já configurado para os serviços do `docker-compose.yml` da raiz):

- `VITE_API_BASE_URL`
- `VITE_KEYCLOAK_URL`
- `VITE_KEYCLOAK_REALM`
- `VITE_KEYCLOAK_CLIENT_ID`
